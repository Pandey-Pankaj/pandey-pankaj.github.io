# Pankaj Pandey Academic Portfolio

A responsive, dependency-free academic website designed for GitHub Pages.

## Files to edit

- `index.html`: homepage and selected highlights
- `research.html`: research program and current projects
- `publications.html`: recent 2024–2026 publications
- `teaching.html`: teaching and research mentoring
- `service.html`: reviewing, grant development, leadership, and presentations
- `cv.html`: concise web summary of academic and professional experience
- `contact.html`: contact details and professional profiles
- `styles.css`: colors, typography, layout, and responsive behavior
- `script.js`: mobile navigation, publication filtering, and current year

The content was prepared from the supplied CV. Update time-sensitive positions, metrics, publications, presentations, and mentoring records as they change. The homepage portrait is stored as `pankaj-pandey.jpg`.

## Preview locally

You can open `index.html` directly in a browser. If Python is installed, preview through a local server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a repository named `yourusername.github.io`.
2. Upload every file in this folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Visit `https://yourusername.github.io` after deployment completes.

For a normal project repository, use the same Pages settings. Relative links allow the site to work under `https://yourusername.github.io/repository-name/`.
